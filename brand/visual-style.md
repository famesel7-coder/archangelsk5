# Visual Style — Архангельск 5

**Статус:** актуальная рабочая система после серии итераций презентации  
**Обновлено:** 2026-08-18  
**Source of truth:** последние одобренные тёмные слайды + пользовательские правки в чате.

## 1. Главная идея

Текущий стиль проекта — **тёмная кинематографичная корпоративная инфографика**, где данные, реальные изображения и локальная тематика Архангельска работают как единая композиция.

Ключевой принцип: **не «север ради севера», а Архангельск, логистика, розница, люди, сервис и территория**.

Визуал должен ощущаться:

- технологичным;
- премиальным;
- спокойным и уверенным;
- локальным;
- современным;
- содержательным, а не декоративным.

## 2. Цветовая система

Основные цвета презентации:

1. **тёмный сине-зелёный / графитовый фон**;
2. **зелёный** — главный активный цвет;
3. **серый** — основной сравнительный / вторичный цвет;
4. **белый** — типографика и ключевые значения.

### Основной фон

Рабочий диапазон:

- `#071D23`
- `#062128`
- `#08272C`
- `#0A2B30`
- более глубокие тени: `#031419` / `#04191E`.

Фон не должен выглядеть как чистый чёрный. Нужна лёгкая teal/green глубина.

### Основной зелёный

- `#00B95A`
- `#00C867`
- `#12C86A`
- глубокий зелёный для градиентов: `#00763F` / `#005E37`.

Яркий зелёный — для ключевых данных, активных линий, маркеров и акцентов.

### Серый

- `#8EA8B0`
- `#9AADB3`
- `#667D84`
- более тёмный UI-gray: `#263A40`.

Серый — не декоративный цвет, а полноценная часть системы: рынок, сравнение, прошлый период, secondary data.

### Белый

- `#F7F8F7`
- `#EEF2F1`.

### Красный

Красный не является фирменным цветом этого проекта. Разрешён только как **семантический negative** в графиках, когда необходимо показать отрицательное значение.

### Пропорция

Ориентир:

- 70–80% dark teal / charcoal;
- 10–15% white;
- 8–12% green;
- 3–8% gray;
- red только точечно для negative data.

## 3. Типографика

- современный нейтральный grotesk / neo-grotesk;
- качественная кириллица;
- заголовки крупные и жирные;
- основной текст regular/medium;
- цифры должны быть максимально читаемыми;
- uppercase допустим, но не обязателен для каждого заголовка.

Иерархия:

1. headline;
2. ключевая цифра / вывод;
3. data labels;
4. поясняющий текст.

Не использовать декоративные шрифты. Не придумывать точное название семейства без исходника.

## 4. Сетка

Рабочий формат: **1920×1080, 16:9**.

Сетка должна быть заметна в композиции, но не выглядеть нарисованной поверх слайда.

Production guideline:

- 12 колонок;
- внешние поля около 80–96 px;
- gutter около 24–32 px;
- вертикальный ритм кратен 8/16/24/32 px;
- элементы в одном ряду должны иметь общие оптические оси.

Это production guideline, а не измеренный фирменный стандарт.

### Важное правило

**Разнообразить верстку внутри сетки, а не ломать сетку ради креатива.**

Допустимые композиции:

- 7/5 — данные + visual;
- 8/4 — крупный график + объяснение;
- 6/6 — сравнение;
- full-width chart + нижний visual strip;
- map hero + боковая колонка;
- photo mosaic 2–3 изображения + данные;
- один крупный visual crop + небольшая data-зона;
- асимметричная композиция с сохранёнными baseline и margins.

Не делать все слайды одинаковыми.

## 5. Фотография — теперь ключевой инструмент

Последние итерации подтвердили, что **реалистичные тематические изображения усиливают стиль**.

Предпочтительные сюжеты:

- Архангельск и область;
- трассы и удалённая логистика;
- грузовики;
- РЦ / склады;
- магазины Пятёрочки;
- сотрудники и клиенты;
- онлайн-заказ, смартфон, доставка;
- сборка заказа;
- fresh / ФРОВ;
- пекарня;
- локальный ассортимент;
- порт, суда и грузовая инфраструктура — когда это связано со смыслом слайда;
- карты региона, маршруты, точки доставки.

### Обработка фото

Фото должны быть:

- реалистичными и нативными;
- тёмными по общей тональности;
- интегрированными через teal/green color grading;
- без очевидной AI-неестественности;
- без лишних логотипов и выдуманного брендинга;
- без дублированных кабин, колёс, дверей, людей и других артефактов.

Фото можно использовать как:

- full-bleed фон;
- правый/левый visual panel;
- горизонтальный strip;
- 2–3-photo mosaic;
- вырезанный hero-object;
- background crop с затемнением под данные.

## 6. Архангельск вместо generic North

Не привязывать дизайн автоматически к словам «Север», «северный», «арктический».

### Не использовать как дефолтный символ

- северную звезду;
- компас как главный знак;
- северное сияние только ради атмосферы;
- маяк;
- generic snowy mountains, если они никак не связаны с содержанием.

Северное сияние допустимо только как вторичный атмосферный слой, если оно реально помогает композиции и не становится главным смыслом.

Приоритет — **Архангельск и бизнес-контекст**: территория, логистика, магазин, РЦ, доставка, локальный ассортимент, люди, карта, портовая инфраструктура.

## 7. Графический язык

### Линии и маршруты

Тонкие зелёные или серые линии работают как:

- путь;
- доставка;
- связь точек;
- динамика;
- движение данных.

Они должны иметь смысл, а не быть декоративным шумом.

### Карты

Карты — сильный мотив проекта.

Использовать:

- тёмную карту;
- тонкий серо-зелёный контур;
- яркие green nodes;
- маршруты;
- подписи только там, где нужны;
- крупный crop территории вместо мелкой «карты России целиком», если смысл локальный.

### Иконки

- тонкий stroke;
- monochrome green / white / gray;
- простые;
- одинаковая система толщины;
- не превращать слайд в UI dashboard.

## 8. Плашки и карточки

**Плашек должно быть меньше.**

Последние правки: не ставить под каждый текст отдельную карточку.

Плашка допустима для:

- короткого label;
- статуса;
- названия региона;
- очень короткого KPI;
- одного смыслового акцента.

Не использовать большие rounded cards как фон под обычный текст, если текст может стоять прямо на поле.

Предпочитать:

- свободный текст;
- линии-разделители;
- тонкие рамки;
- градиентное затемнение под фото;
- layout через whitespace.

## 9. Data visualization

Основная логика:

- green = Пятёрочка / рост / текущий акцент;
- gray = рынок / сравнение / предыдущий период;
- red = только negative data;
- gridlines слабые;
- оси и подписи вторичны;
- ключевые значения крупные.

График должен быть частью композиции, а не вставленным Excel-chart.

Хорошо работают:

- крупные bar charts;
- line charts с 1–2 главными линиями;
- карта + KPI;
- график + тематическое фото;
- data + один большой contextual visual.

## 10. Визуальная библиотека по смысловым слайдам

### Операционная модель

Карта + РЦ + маршруты + реалистичная логистика.

### Динамика доли рынка

Главный график + 1–3 тематических визуала: магазин, локальный ассортимент, fresh, клиентский опыт.

### Масштабирование / NPS

Магазин, сотрудник-клиент, fresh-зона, чистый торговый зал. Можно собирать photo mosaic.

### Фокусы 2026

Каждый фокус должен иметь **собственный визуальный образ**, а не только иконку:

- Пекарня — хлеб / печь / пекарня;
- ФРОВ — овощи и фрукты;
- ТОП 50- NEW — новый ассортимент / товар / NEW;
- Online — приложение / корзина / сборка / доставка;
- Апельсин — апельсин / карта / программа / digital card.

### Online

Грузовик, доставка, смартфон, сборка заказа, склад/РЦ, удалённый маршрут.

### Конкурентная борьба

Основной chart + visual drivers: цена, онлайн, сервис, fresh.

### Апельсин

Карта, карта/приложение программы, сотрудники-амбассадоры, зоны оформления, продажи.

## 11. Логотип

Логотип Пятёрочки — важный brand anchor.

- использовать официальный asset, если он доступен;
- не перерисовывать логотип по памяти;
- не генерировать искажённый wordmark;
- на объектах допустим круглый знак «5» без надписи, если это соответствует задаче;
- логотип не должен становиться декоративным паттерном.

## 12. Что нельзя делать

- generic PowerPoint cards;
- много плашек под обычный текст;
- одинаковый layout на всех слайдах;
- случайные neon effects;
- blue/purple cyberpunk;
- generic «северная» символика как главный смысл;
- маяки как универсальный визуал;
- северные звёзды/компасы как постоянный мотив;
- перегруженное северное сияние на каждом слайде;
- очевидный stock без обработки;
- неестественные AI-фото;
- выдуманные логотипы;
- переписывание исходного текста ради дизайна.

## 13. Главный тест качества

Слайд считается успешным, если:

1. контент читается за 2–3 секунды;
2. сетка собрана чисто;
3. green + gray + dark field узнаются сразу;
4. есть один главный visual anchor;
5. тематические изображения помогают смыслу;
6. нет лишних плашек;
7. композиция отличается от соседних слайдов;
8. стиль выглядит premium и corporate, а не как шаблон;
9. визуал связан с Архангельском / бизнесом, а не с абстрактным «севером»;
10. можно убрать любой декоративный элемент, который не несёт функцию.
