# Архангельск 5 — Visual System

Репозиторий хранит формализованный визуальный язык проекта «Архангельск 5» и инструкции для генерации презентационных слайдов в этом стиле.

## Источник анализа

Первичный анализ выполнен по трем предоставленным визуальным референсам 17.08.2026:

- главный key visual «Новые вызовы / Время возможностей»;
- чистый фон с перспективной линейной сеткой и световыми дугами;
- серия экранов/носителей «Время возможностей / Регистрация».

## Что зафиксировано

- `brand/visual-style.md` — визуальная ДНК, композиция, типографика, графика, правила do/don't;
- `tokens/design-tokens.json` — машинно-читаемые дизайн-токены и степень уверенности;
- `prompts/slide-agent.md` — системный промпт для агента, который должен создавать новые креативные слайды в заданном стиле.

## Важное ограничение

Точное семейство шрифтов по растровым изображениям не подтверждено. В базе фиксируется характер типографики и роли начертаний, но конкретное название шрифта помечено как `unconfirmed` до получения исходных файлов, брендбука или CSS/Figma.

## Принцип

Цель — не копировать исходные макеты, а извлечь их визуальную грамматику: темно-зеленое поле, белая техническая контурная графика, перспективные лучи, неоново-зеленые световые дуги, крупная гротескная типографика и локальные архитектурные/городские образы.
