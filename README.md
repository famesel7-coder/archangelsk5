# Архангельск 5 — Visual System

Репозиторий хранит актуальную систему дизайна презентации проекта «Архангельск 5» и инструкции для генерации новых слайдов.

## Текущая версия

**Обновлено:** 18.08.2026

После серии дизайн-итераций система уточнена. Основное направление теперь:

- тёмный teal / charcoal фон;
- green как главный активный цвет;
- gray как основной сравнительный цвет;
- white typography;
- реалистичные тематические изображения;
- карты, маршруты, логистика, магазины и люди;
- разнообразная верстка внутри строгой сетки;
- минимум плашек и карточек.

## Важная корректировка арт-дирекшена

Проект не должен строиться на generic «северной» эстетике.

Не использовать автоматически маяки, северные звёзды, компасы и северное сияние. Визуальная локальность должна идти прежде всего от **Архангельска и бизнес-контекста**: территория, розница, логистика, РЦ, доставка, сотрудники, fresh, пекарня, online, локальный ассортимент, карты и маршруты.

## Файлы

- `brand/visual-style.md` — актуальная визуальная ДНК, сетка, изображения, графики, do/don't;
- `tokens/design-tokens.json` — машинно-читаемые токены;
- `prompts/slide-agent.md` — инструкция для агента, создающего новые слайды.

## Правило работы с PPT

Если в работе используется драфт PPT:

- PPT — источник правды для текста и цифр;
- текст не переписывать;
- скрытые слайды не проектировать;
- исходную верстку PPT не считать дизайн-референсом — это только прототип контента.

## Формат

Основной формат слайдов: **1920×1080, 16:9**.

Production guideline: 12-колоночная сетка, строгие оптические оси и разнообразные композиции внутри единой системы.

## Типографика

Точное семейство шрифта пока не подтверждено. В системе фиксируется характер типографики, но конкретный font family остаётся `unconfirmed` до появления исходников.

## Принцип

Цель — не сделать один шаблон, а поддерживать устойчивую art-direction систему, в которой каждый слайд отличается по композиции, но узнаётся как часть одной тёмной green/gray презентации «Архангельск 5».
